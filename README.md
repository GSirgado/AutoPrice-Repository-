# AutoPrice-Repository-
Esta é uma plataforma que conecta compradores e vendedores de carros e motas de forma simples, rápida e segura, com um sistema de avaliador inteligente de preços, sendo capaz de analisar vários fatores como marca, modelo, ano, quilometragem e condição geral do veículo, fornecendo uma estimativa de preço de mercado.
